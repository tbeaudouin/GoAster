# Task planning

Use whenever the user asks to plan a task, project, or implementation. Load [project-memory](../project-memory/SKILL.md) to find or create the project notes. Save `PLAN-<task-name>.md` inside `memory/projects/<project-name>/`, beside that project's notes, using a short lowercase hyphenated task name; never save it directly in `memory/projects/`. Reuse or update only a plan for that same task. Keep it concise: goal, steps, and completion checks. Tell the user the path. A plan-only request does not authorize implementation; an approved coordinated source workflow may implement its plan without another approval.

On resume, reconcile an existing same-task plan with current owning skill guidance instead of blindly reusing obsolete prerequisites.
