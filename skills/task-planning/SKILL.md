# Task planning

Use whenever the user asks to plan a task, project, or implementation. Load [project-memory](../project-memory/SKILL.md) to find or create the project notes. Save `PLAN-<task-name>.md` beside them, using a short lowercase hyphenated task name. Reuse or update only a plan for that same task. Keep it concise: goal, steps, and completion checks. Tell the user the path. Planning does not authorize implementation.
