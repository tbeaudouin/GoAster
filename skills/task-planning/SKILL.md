# Task planning

Use whenever the user asks to plan a task, project, or implementation. Load [project-memory](../project-memory/SKILL.md) to find or create the related project notes. Create or update PLAN.md beside those notes. Keep it concise: goal, ordered steps, and how to check completion. Reuse an existing relevant plan rather than creating duplicates. Tell the user where the plan is saved. Planning does not authorize implementation.
