# GoAster fork

Prepare the authenticated user's public fork of `tbeaudouin05/GoAster` and its `goaster-customization` branch. Use [github-auth](../github-auth/SKILL.md) to identify the account via the authenticated API and [git-repositories](../git-repositories/SKILL.md) for the checkout path. Inspect the upstream and any existing fork, branch and checkout; verify the fork belongs to the account and has the expected upstream. Use the existing branch when present, otherwise create it from the fork's default branch. Create a missing public fork and checkout as needed. Preserve unrelated work. Never write to the upstream repository.

For the coordinated source workflow, describe this setup in the coordinator's single approval and continue under it, including branch reuse and ordinary git operations. Standalone fork setup needs approval for its public creation and setup; it does not authorize later changes or deployment. Verify the resulting fork and branch. If a creation has an uncertain outcome, inspect it before any retry. Report actual failures without exposing credentials.
