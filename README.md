# 🚀 Quickstart

[Set up your agent on the GoAster website](https://goaster.fly.dev) in **about 5 minutes**.

> GoAster is completely free. You only pay for your Hetzner server and OpenAI subscription.

## ✨ Meet GoAster

Inspired by OpenClaw and PicoClaw. Like a minimal, open-source Codex or Claude Code, running on your own server and yours to extend.

The shared core stays minimal. Your fork becomes whatever you need.

## Why GoAster?

- **Quick to start:** Follow a quick, guided setup on a small, affordable server.
- **Own your AI:** Keep your agent's skills, projects, and work knowledge on a server you control.
- **Make it your own:** Let the agent change its source code and create skills for useful automation.
- **Grow together:** Discover community skills and features, then share improvements with other builders.
