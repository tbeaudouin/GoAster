Quickstart:

Just go to https://goaster.fly.dev and set up your agent for free on your own Hetzner server in about 5 minutes. GoAster setup is free; costs apply for the Hetzner server and your OpenAI subscription.

GoAster is an AI agent for small startup teams doing software, analytics, product, and business work. It is a practical companion with a bit of stardust:

- Follow a quick, guided setup on a small, affordable server.
- Keep your agent's skills, projects, and work knowledge on a server you control.
- Let the agent change its source code and create skills for useful automation.
- Discover community skills and features, then share improvements with other builders.

Start with the setup site, then see the idea in motion:

- [Introduction](https://www.youtube.com/watch?v=GMn6PRiqOA8)
- [Why GoAster](https://www.youtube.com/watch?v=uPSd3cpE2zk)

For the longer version, read the [GoAster manifesto](https://goaster.fly.dev/manifesto). Start small, keep your bearings, and let your agent grow alongside the work that matters to your team. Bring a small task, a curious mind, and perhaps a helmet. ★
